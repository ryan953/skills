Task Lifecycle

A person enters a task and it is todo. Someone reads it and starts it. Creating a PR moves it into review, and a task can have several PRs. When every linked PR is merged and every subtask is done, the task becomes done by itself. Closed PRs don't count. At any point before done, someone can decompose the task into subtasks: it becomes a parent and keeps its status.

Lifecycle map

Two loops, one band each. Every column is a status, and inside it are the things that can happen to something in that status. A card either moves it to another column, leaves it where it is, or creates something new: a subtask, which starts in Todo, or a PR, which starts in Awaiting review. Hover or focus a card to draw where it leads.

moves to another status creates a task or PR the author's fix for this status status unchanged automatic, nobody clicks it
